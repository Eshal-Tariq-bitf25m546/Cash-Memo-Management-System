# Cash Memo Management System

A console-based Cash Memo Management System developed in C++ as an Object-Oriented Programming (OOP) project.

## Features
- Store customer information
- Record memo number and date
- Add multiple products to a bill
- Manage product quantities and rates
- Automatically calculate individual item amounts
- Calculate the grand total
- Display a formatted cash memo

## Concepts Used
- Classes and Objects
- Encapsulation
- Constructors
- Getters and Setters
- Operator Overloading
- Friend Functions
- Vectors
- Composition
- Stream Input/Output

## Technologies
- C++
- Standard Template Library (STL)

## Project Purpose
This project was developed to practice and strengthen fundamental C++ Object-Oriented Programming concepts through a practical billing-system application.
